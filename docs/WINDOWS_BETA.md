# SlideSync Local — Windows Beta

## Для користувачів

Цільова система — **Windows 10 або 11, x64 (Intel/AMD)**. Windows ARM64 і 32-бітні системи не входять до цієї бети. Це той самий Electron-застосунок, що й macOS: PDF, QR, попереднє завантаження, синхронізація, малювання, опитування та панель стану підключень. Node.js і термінал користувачам не потрібні. Під час показу інтернет не потрібен.

Наявність конфігурації збірки не означає, що інсталятор уже створено або перевірено на Windows. Поточні результати дивіться в [VALIDATION.md](VALIDATION.md).

1. Отримайте `SlideSync-Local-0.2.0-beta.1-windows-x64-setup.exe` та `SHA256SUMS` із довіреного джерела. Інсталятор містить усі компоненти для роботи без інтернету.
2. Запустіть інсталятор. Встановлення виконується для поточного користувача без прав адміністратора; можна обрати каталог. Відкрийте **SlideSync Local** через меню «Пуск» або ярлик.
3. Якщо Windows запитає доступ через брандмауер, дозвольте застосунку вхідні з’єднання лише в приватних мережах. Не вимикайте брандмауер. Профіль мережі змінюйте на приватний лише для довіреної мережі.
4. Натисніть «Вибрати файл», оберіть PDF і натисніть «Завантажити PDF».
5. Приєднайте телефони до тієї самої LAN, відскануйте QR у Safari або Chrome та дочекайтеся попереднього завантаження.
6. Перемикайте слайди, малюйте й запускайте опитування. Залишайте застосунок відкритим; не закривайте кришку ноутбука.

Застосунок блокує автоматичний сон під час роботи, але не захищає від ручного сну, закриття кришки чи вимкнення живлення. Закриття вікна або `Ctrl+Q` потребує підтвердження. Після виходу телефони від’єднуються, тимчасові PDF/JPEG і голоси видаляються. Наступний запуск створює новий QR; PDF завантажують знову.

Збережені питання та останній порт залишаються у `%APPDATA%\SlideSync Local\desktop-state.json`. Там немає PDF, голосів або ключів сесії. Оновлення встановлюють вручну новим інсталятором. Для видалення скористайтеся «Параметри → Програми». Збережені питання автоматично не видаляються; за потреби видаліть каталог даних окремо після закриття застосунку.

### Підпис і перевірка

Безкоштовна бета **не має цифрового підпису видавця Windows**. SmartScreen або корпоративна політика можуть заблокувати запуск. Перевіряйте джерело та SHA-256. Не вимикайте SmartScreen, Defender чи інші засоби захисту. Якщо політика організації забороняє непідписані застосунки, зверніться до адміністратора.

```powershell
Get-FileHash .\SlideSync-Local-0.2.0-beta.1-windows-x64-setup.exe -Algorithm SHA256
```

Порівняйте результат із `SHA256SUMS`, отриманим із довіреного джерела. Контрольна сума перевіряє цілісність файла, а не особу видавця. Автоматичного оновлення й публікації в Microsoft Store немає.

### Якщо телефон не приєднується

- Гостьовий Wi-Fi та ізоляція клієнтів можуть блокувати зв’язок між пристроями.
- Перевірте дозвіл встановленого `.exe` SlideSync Local для приватної мережі в брандмауері Windows; дозвіл окремого Node.js недостатній.
- За наявності VPN оберіть адресу Wi-Fi у QR-панелі. Використовуйте актуальний QR.
- Якщо порт 3000 зайнятий, застосунок автоматично обере інший порт, не зупиняючи наявний сервер. Правило лише для порту 3000 не допоможе застосунку на іншому порту.
- HTTP/WS не шифруються. Використовуйте довірену LAN й не відкривайте порт в інтернет.

Ліміти: PDF до 40 МіБ / 150 сторінок, без пароля. Телефони отримують JPEG і стан показу; PDF обробляється на комп’ютері. Деталі: [українська інструкція](README.uk.md).

## Для розробників

Збирайте **на Windows x64 з Node.js x64 22.13+**. Не копіюйте `node_modules` із macOS. Hook перевіряє ОС, архітектуру й нативний canvas. Кросзбірка з Mac та Windows ARM64 навмисно відхиляються.

```powershell
npm ci
npx playwright install chromium
npm test
npm run test:desktop
npm run desktop:dist:win
```

Результат — `dist/SlideSync-Local-0.2.0-beta.1-windows-x64-setup.exe`. `npm run desktop:pack:win` створює лише каталог `dist/win-unpacked/`. Інструменти збірки потребують інтернету; готовий застосунок — ні. Команди містять `--publish never`; інсталятори й згенеровані іконки ігноруються Git.

Перевірка запакованого застосунку з окремим тимчасовим профілем:

```powershell
$env:SLIDESYNC_DESKTOP_EXECUTABLE = (Resolve-Path '.\dist\win-unpacked\SlideSync Local.exe').Path
npm run test:desktop
Remove-Item Env:SLIDESYNC_DESKTOP_EXECUTABLE
```

Тест перевіряє завантаження PDF, синхронізацію браузера, збереження питань після перезапуску, зміну порту при конфлікті та очищення. Особистий профіль не використовується. Для встановленої версії задайте шлях до встановленого `.exe` тією самою змінною.

### Ручна збірка в GitHub Actions

Після додавання цих змін у репозиторій відкрийте **Actions → Windows desktop beta → Run workflow**. Workflow запускається лише вручну на Windows x64, виконує серверні й desktop-тести, збирає інсталятор, встановлює його в тимчасовий каталог і перевіряє встановлений застосунок з ізольованим профілем. Лише після успіху зберігає artifact з `.exe`, `SHA256SUMS` та цією інструкцією на 14 днів. Workflow не створює релізів і не публікує інсталятор автоматично. GitHub використовується лише для збірки, а не під час показу.

### Перед розповсюдженням

На чистому Windows-комп’ютері перевірте встановлення без адміністратора, запуск без Node.js та інтернету, доступ телефонів через приватну Wi-Fi-мережу, малювання й голосування, повторне підключення, HTTP fallback, скасування виходу, повторний запуск, оновлення зі збереженням питань і видалення. GitHub runner не замінює фізичні телефони та брандмауер реального користувача.

Конфігурація використовує звичайний NSIS, а не `nsis-web`; компоненти входять до інсталятора. `asar: false` зберігає доступні шляхи до PDF worker, локальних шрифтів/WASM і нативного canvas. Права ведучого, приватність `presence` та ізоляція Electron однакові на macOS і Windows.

Джерела: [платформи Electron](https://github.com/electron/electron/blob/main/README.md), [NSIS у electron-builder](https://www.electron.build/v26/docs/nsis/).
