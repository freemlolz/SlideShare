# Протокол перевірки MVP

Дата: 29 жовтня 2026 року.

Середовище: macOS, Node.js 22.23.4, npm 10.9.9. Встановлені залежності: Express 5.3.0, ws 8.22.0, multer 2.5.0, PDF.js 6.4.299, @napi-rs/canvas 1.0.13, qrcode 1.5.4, Playwright 1.64.1.

| Перевірка | Результат |
| --- | --- |
| Інтеграційні серверні тести `npm test` | 12/12 пройдено, пропусків немає |
| Двадцять п’ять одночасних WebSocket-клієнтів | Усі отримали однаковий новий індекс слайда |
| Звернення через LAN-адресу ноутбука | Перегляд дозволено, керування заборонено навіть із ключем ведучого |
| Chromium: повний сценарій, fallback, відсутній ключ | 3/3 пройдено |
| WebKit з мобільними налаштуваннями iPhone: ті самі сценарії | 3/3 пройдено |
| Перемикання кешованого слайда | Нових HTTP-запитів JPEG не було |
| Рендеринг PDF, поворот, українські назви | Пройдено |
| Обмеження розміру/сторінок, пошкоджений PDF, пароль, timeout | Пройдено; поточний показ зберігається |
| Звільнення блокування upload перед відповіддю | Послідовні запити після завершення відповіді проходять |
| Видалення тимчасових даних при штатній зупинці | Перевірено автоматично |
| `npm audit --omit=dev --audit-level=moderate` | 0 відомих вразливостей на час перевірки |
| Візуальний перегляд скріншотів пульта та мобільного переглядача | Перевірено; слайд не обрізається, елементи доступні |

Виявлені під час розробки та виправлені проблеми: зміна API очищення PDF.js у версії 6; затримка звільнення upload після вже надісланої відповіді; запізніле закриття старого сокета після нового підключення; вплив watchdog на затримку reconnect. Ці виправлення входять до поставки.

## Що не перевірено фізично

- Реальний iPhone із системним Safari, блокуванням екрана та системними мережевими налаштуваннями.
- Реальний Android із Chrome.
- Місткість конкретної Wi-Fi-точки доступу та одночасне завантаження презентації на 25 фізичних телефонах.
- Мережа з від’єднаним WAN, captive portal, гостьовою ізоляцією та різні режими хотспотів.
- Windows/Linux як середовища запуску сервера; код і залежності розраховані на підтримувані платформи Node.js, але тут виконані лише на macOS.

Для цих пунктів є ручний чеклист у `TESTING.md`. Результати автоматизації не є підтвердженням виконання цих польових перевірок.
