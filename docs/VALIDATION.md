## Оновлення 30 жовтня 2026 року

Додано спільне малювання ведучого та особистий перегляд історії на телефонах, згодом — плавне згасання ліній. `npm test`: 20/20 пройдено — 13 інтеграційних і 7 перевірок шару малювання та анімації. `npm run test:browser`: 14/14 пройдено — по 7 у Chromium і WebKit. Разом пройдено 34 перевірки, пропусків немає.

Нові перевірки охоплюють олівець/пензлик/маркер, різні розміри, тиск і нормалізовані координати, передавання незавершеної лінії, очищення за 5 секунд, постійні малюнки, зміну слайда/PDF, старі пакети після очищення, обмеження пам’яті та заборону малювання учасникам. На телефоні перевіряються незалежний перегляд, повернення до поточного кадру, приховування шару іншого слайда й запізніле завантаження історичного JPEG. HTTP fallback також передає малюнки.

Візуально перевірено знімки пульта з панеллю інструментів і телефона з трьома різними лініями. Вони створені автоматизованими браузерами, не фізичними телефонами. Залежності й вимога відсутності хмарних сервісів не змінилися.

Браузерні перевірки підтвердили проміжну прозорість Canvas перед завершенням п’ятисекундного часу життя, тобто реальне плавне згасання в обох рушіях. Головний README скорочено й переписано англійською; докладну українську інструкцію перенесено до `docs/README.uk.md`. Банер і бейджі — локальні SVG без зовнішніх запитів. Посилання документації та рендеринг банера перевірено локально.

## Швидкі опитування — 30 жовтня 2026 року

Фінальний `npm test`: 37/37 пройдено. Фінальний `npm run test:browser -- test/browser/polls.spec.mjs`: 8/8 пройдено, по 4 сценарії Chromium і WebKit. Перевірено CRUD і збереження питань, 2/4 відповіді, серверний дедлайн 10 секунд, автоматичні результати, власний голос після перезавантаження, HTTP fallback, скасування, повернення до PDF та запізнілий голос попереднього раунду.

Регресійні сценарії синхронізації, малювання, згасання й особистого перегляду також пройшли під час розробки. Після посилення перевірки cookie повторно пройдено всі 6 браузерних сценаріїв синхронізації та reconnect. Фізичні пристрої не використовувалися.

Під час перевірок виправлено блокування кнопок нового раунду старим HTTP-запитом, втрату персоналізації в сокеті без cookie та періодичне перезаписування тексту кнопки завершеного опитування, яке заважало кліку у WebKit. Завершені результати більше не мають активного таймера перемальовування. Сценарій результатів у WebKit додатково пройдено двічі поспіль, зокрема з натисканням тривалістю 250 мс.

## Виправлення запуску й плаваючий віджет — 30 жовтня 2026 року

Причину помилки JSON підтверджено на запущеному процесі: `POST /api/host/polls/start` повертав HTML `404`, оскільки процес стартував до додавання серверних маршрутів. Після погодженого перезапуску на тому самому порту збережене питання користувача залишилося в бібліотеці, успішно запустилося з віджета та автоматично перейшло до результатів. PDF і QR сесії при перезапуску скинуто, як попереджено користувача.

`npm test`: 39/39 пройдено. `npm run test:browser -- test/browser/poll-launcher.spec.mjs`: 6/6 пройдено. Перевірено перетягування й згортання віджета, запуск у повноекранному режимі, відсутність віджета та незапущених питань на телефоні, повернення до слайдів, перехід до редактора та зрозумілі помилки старого сервера без втрати бібліотеки.

Повторний `npm run test:browser -- test/browser/polls.spec.mjs test/browser/sync.spec.mjs`: 14/14 пройдено. Ці перевірки включають звичайний запуск, голосування, автоматичні результати, HTTP fallback, reconnect, перезавантаження й заміну презентації у Chromium та WebKit. Фізичні телефони не перевірялися.

## Панель стану учасників — 30 жовтня 2026 року

`npm test`: 48/48 пройдено. `npm run test:browser`: 30/30 пройдено, по 15 у Chromium та WebKit. Після останнього уточнення приватної версії стану повторно пройдено всі 9 модульних та серверних перевірок presence.

Нові перевірки охоплюють об’єднання вкладок одного профілю, свіжість pong/HTTP, межу від’єднання 35 секунд, повторне приєднання зі збереженням мітки, готовність через HTTP, заміну deck, обмеження реєстру, видалення записів і повернення після видалення. Окремо перевірено, що непідтверджені cookie не створюють фантомних записів, а учасницькі HTTP/WS-відповіді не містять приватного списку.

Браузерні сценарії перевіряють дві вкладки одного профілю, інший профіль із заблокованим WS, прогрес завантаження, від’єднання, reconnect і видалення старого запису. Час від’єднання прискорений ін’єкцією тестового серверного годинника; це не випробування реальної Wi-Fi-мережі. Знімок панелі перевірено візуально. Поточний користувацький сервер не перезапускався без нового погодження.

## macOS Beta — 31 жовтня 2026 року

Зібрано `SlideSync-Local-0.2.0-beta.1-x64.dmg` на Intel Mac із macOS 15.5. Мінімум у метаданих — macOS 14.0; окремо на macOS 14 не перевірено. Застосунок включає Electron 45.2.1 і нативний x64 canvas, не потребує зовнішнього Node.js. ARM64-збірку не створено й не перевірено; кросзбірка навмисно блокується до підготовки відповідного нативного середовища.

- `npm test`: 52/52 пройдено, включно з чотирма перевірками desktop-сховища, вільного порту та політики переходів.
- `npm run test:browser`: 30/30 пройдено у Chromium та WebKit.
- `npm run test:desktop`: пройдено для development-запуску та повторно для запакованого `.app`. Перевірено PDF → JPEG, preload, синхронізацію браузера, sandbox/context isolation, відсутність Node у сторінці, тимчасову Chromium-сесію, збереження опитувань після зміни порту й очищення тимчасових PDF/JPEG на виході. Усі запуски ізольовані від особистого профілю.
- `codesign --verify --deep --strict`: пройдено; підпис ad-hoc, не Developer ID. `hdiutil verify`: образ DMG справний. SHA-256 міститься у `dist/SHA256SUMS` поруч з інсталятором.
- `npm audit --omit=dev`: 0 відомих уразливостей на момент перевірки. Під час встановлення інструментів npm повідомив про 15 moderate уразливостей dev-залежностей пакувальника; ці dev-пакети не включені до застосунку.

Знімок desktop-інтерфейсу з демонстраційним PDF перевірено візуально. Поточний сервер користувача на порту 3000 не зупинявся. Немає перевірки Gatekeeper після завантаження на чистий Mac, нотаризації Apple, фізичних телефонів або Apple Silicon. DMG створено локально; GitHub-реліз і автоматичні оновлення не налаштовано.

## Android Beta — 1 листопада 2026 року

Створено окремий Android-пульт у `android/`: системний вибір PDF, локальний рендеринг JPEG, foreground-сервіс, HTTP/WebSocket, QR та нативні кнопки керування. Переглядач використовує спільні файли `public/`; окремий WS-порт перевірено на локальному браузерному стенді у Chromium та WebKit. Це не перевірка реальної Wi-Fi-мережі.

Фінальна збірка `npm run android:beta` успішна: 4/4 модульних Android-тести, `lintRelease` — 0 помилок, 6 попереджень. Регресійні `npm test` — 52/52, `npm run test:browser` — 32/32. APK має назву `SlideSync-Local-Android-0.1.0-beta.1.apk`; файл SHA-256 розташований поруч у `dist/android/`.

Перед проханням користувача припинити емуляторні перевірки завершилися 3/3 інструментальні тести на окремому AVD: відхилення некоректного PDF і скасування, PDF → JPEG/HTTP/WS та захист керування, запуск foreground-сервісу/перемикання/поворот/очищення. Після прохання емулятор зупинено; наскрізний сценарій браузера зі справжнім Android-бекендом не завершено. Останнє виправлення реєстрації сокета після зупинки перевіряється модульним тестом, без повторного запуску емулятора.

APK підписаний локальним приватним ключем, який не входить до Git. Це тестова бета для прямого встановлення, не Google Play-реліз. Фізичний Android, iPhone/Safari, встановлення з браузера, hotspot, блокування екрана та обмеження батареї залишаються для ручної перевірки користувачем. Малювання й опитування в цій мобільній беті відсутні. Ноутбучний сервер користувача не перезапускався.

## Windows desktop — 2 листопада 2026 року

Додано Windows x64 target для того самого Electron-застосунку: автономний NSIS-інсталятор українською, встановлення для поточного користувача без підвищення прав, ярлики та ручна збірка через `npm run desktop:dist:win`. UI більше не називає Windows-комп’ютер Mac. Конфігурація macOS DMG збережена.

На Intel macOS із Node.js 22.23.4 виконано:

- `npm test`: 53/53 пройдено, без пропусків, включно з LAN-перевіркою та новою перевіркою packaging hook. Hook приймає лише нативні macOS x64/arm64 і Windows x64, вимагає правильний canvas і відхиляє іншу ОС/архітектуру або відсутній бінарник.
- `npm run test:desktop`: development-запуск і зібраний Intel `.app` пройдено з ізольованими тимчасовими профілями. Перша паралельна перевірка `.app` захопила тимчасові каталоги браузерних серверів і впала на очищенні; повторний окремий запуск пройдено без змін коду.
- `npm run test:browser`: 32/32 пройдено у Chromium та мобільному WebKit; це не перевірка фізичного iPhone.
- `npm run desktop:pack -- --x64`: Intel `.app` зібрано успішно, підпис ad-hoc, нотаризацію не виконано.
- Конфігурація перевірена валідатором установленого electron-builder 26.18.1; NSIS генерує `MUI_LANGUAGE "Ukrainian"`. YAML workflow успішно прочитано локальним парсером.

Початкові sandbox-запуски блокували мережеві порти й запуск Electron. Наведені успішні перевірки виконано з доступом до локальних портів та ізольованого вікна, без перезапуску користувацького сервера.

**Windows `.exe` тут не зібрано й не запущено.** Ручний workflow `.github/workflows/windows-desktop.yml` підготовлено, але не виконано: він має зібрати інсталятор на Windows x64, встановити його в тимчасовий каталог, перевірити development і встановлений застосунок та зберегти artifact із SHA-256. Перевірки на macOS не підтверджують роботу Windows, SmartScreen, брандмауера або фізичних телефонів. Інструкція та ручний чеклист: [WINDOWS_BETA.md](WINDOWS_BETA.md).

## Польові перевірки, що залишаються

- Реальний iPhone із системним Safari, блокуванням екрана та системними мережевими налаштуваннями.
- Реальний Android із Chrome.
- Місткість конкретної Wi-Fi-точки доступу та одночасне завантаження презентації на 25 фізичних телефонах.

- Windows/Linux як середовища запуску сервера; код і залежності розраховані на підтримувані платформи Node.js, але тут виконані лише на macOS.

Для цих пунктів є ручний чеклист у `TESTING.md`. Результати автоматизації не є підтвердженням виконання цих польових перевірок.
