# SlideSync Local

Локальний Node.js-застосунок для синхронного показу PDF у браузерах телефонів через Wi-Fi.

## Обмеження продукту

- Зберігайте роботу без платних API, хмарних сервісів, CDN та інтернет-залежностей під час показу.
- PDF обробляється на ноутбуці; телефони отримують JPEG та стан показу.
- Керування потребує loopback-з’єднання й окремого ключа ведучого. Учасникам доступні перегляд і один голос у поточному опитуванні; запуск та скасування — лише ведучому.
- Зберігайте попереднє завантаження, повторне підключення та HTTP fallback для Safari.
- Реєстр стану учасників приватний: поле `presence` дозволене лише у знімках ведучого через HTTP, WebSocket та heartbeat, ніколи в учасницьких відповідях.
- Інтерфейс і докладна інструкція користувача — українською. Головний `README.md` — короткий, англійською, із локальними зображеннями; українська інструкція міститься в `docs/README.uk.md`.

## Запуск і перевірки

- `npm ci` — встановлення зафіксованих залежностей.
- `npm start` — локальний HTTP/WebSocket-сервер на порту 3000.
- `npm run demo` — створення демонстраційного PDF.
- `npm test` — серверні інтеграційні тести, включно з короткою перевіркою через LAN-інтерфейс.
- `npx playwright install chromium webkit`, потім `npm run test:browser` — браузерні тести.
- Архітектура та технічне завдання розташовані в `docs/`.

## Репозиторій

Не додавайте в Git `node_modules`, тестові тимчасові файли, `.env`, особисті PDF або поточні ключі сесій. Зміни застосунку перевіряйте відповідними тестами; не називайте WebKit-автоматизацію перевіркою фізичного iPhone. Не змінюйте глобальні Git-налаштування користувача.
